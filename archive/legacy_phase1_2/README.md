# Superseded Phase 1/2 sample outputs

The clean distribution omits six early per-game PBP CSVs, their sample
validation report, and the retired `pll_validate.py` script. These files
have no active pipeline consumers and are preserved in the original input ZIP.
Historical phase reports describe their earlier archival location.

Use `data/processed/2026/events.csv` and
`data/processed/2026/validation_report.csv` for the corresponding season-wide
outputs. The active `scripts/pll_pbp_extractor.py` and `scripts/pll_pbp_clean.py`
are retained because the current table builder imports them.

Five-season data, methodology, validation records, and research outputs remain
included to preserve reproducibility.
