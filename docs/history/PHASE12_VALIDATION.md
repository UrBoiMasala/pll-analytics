16 checks. Written to `data/processed/history/phase12_validation_report.csv`
in the same `check_id / check_name / status / n_failures / detail` shape as
every earlier phase.

**Independence.** Checks 1-2 re-hash canonical/raw files from disk rather
than trusting a stored value; check 3 re-reads the Phase 11 report and
manifest rather than assuming they still pass; checks 4-13 and 16 recompute
their target from the actual published Phase 12 CSVs and docs rather than
from intermediate variables inside the script that produced them; check 14
re-runs the entire Phase 12 module and diffs the output by SHA-256.

## A finding the validator surfaced rather than hid

Check 12's first version required every `ACCOUNTING_VALIDITY` row to be
PASS and failed, because building the validation-results CSV surfaced a
genuine, previously-unmeasured fact: `EPA_points_raw` sums to exactly zero
across the league in 2023, 2025 and 2026, but not in 2022 (-0.93) or 2024
(+0.28). The **row-level** identity — the one every player-level use of
`EPA_points_raw` actually rests on — is exact in all 1,023 player-seasons
(max abs diff 5.3e-15). The **season-total** identity is a separate, more
fragile property, and its failure in 2022 plausibly traces to the
already-documented `archers-cannons-2022-6-18` goal-count reconciliation gap
(INFERRED, not re-traced event-by-event in this phase); 2024's smaller
residual has no equally obvious cause and is recorded as an open,
unattributed discrepancy. Check 12 was rewritten to test the invariant that
actually matters (row-level) and to require any season-sum exception to
carry a documented cause rather than silently pass or silently fail — this
is exactly the "existing negative findings are evidence, not inconveniences"
principle applied to a finding this phase produced itself.

## 7. Recommended architecture (Phase 12 brief, Section N)

Four options were named in the brief: **A** (universal value model
defensible), **B** (partial common scale), **C** (role-specific models
only), **D** (data insufficient for any meaningful value model).

**Recommendation: C.**

- **Not A.** No transformation tested — ten cross-position bridges in Phase
  10, plus the new Model Family 5 team-outcome regression in this phase —
  converts `EPA_points_raw` into a cross-role-comparable value without
  either discarding magnitude, assuming the answer, or resting on n=40
  team-seasons for coefficients that are not even per-player weights
  (`CROSS_POSITION_VALUE_PHASE12.md` §§1-3).
- **Not B.** B requires identifying *which* pair(s) of roles are comparable
  and which are not. No pair — not even offense and faceoff, the two
  best-identified roles — was shown comparable on any tested bridge. There
  is no principled subset to carve out as "partially common," so B would be
  an arbitrary partition dressed as a finding.
- **C is supported.** Five separate, single-role models are each
  individually defensible (offense: VIABLE; faceoff and goalie:
  VIABLE_WITH_CAVEAT; defense: ROLE_ONLY as production, never as value),
  each resting on formulas, baselines and reliability estimates Phases 6-10
  already validated. `STATISTICAL_TEWAARATON_SPECIFICATION.md` specifies
  this architecture in full.
- **Not D.** The data are not insufficient for a *meaningful* value model —
  they are insufficient specifically for a *cross-role* one. Within a role,
  production is measured well (offense: ~19,000 career shots; faceoff: the
  cleanest identified skill in the project) and the accounting is exact.
  Calling the data insufficient outright would discard real, validated,
  usable signal.

This determination is not preferred because it is convenient — a working
cross-role Statistical Tewaaraton would have been the more impressive
result. It is the one the evidence in every document this phase produced
actually supports.

## What this validation does NOT prove

- **It does not prove Model Family 5's regression is a good model of team
  success.** It proves the regression is reproducible, its coefficients are
  bootstrap-stable in sign, and its out-of-sample degradation (R² 0.663 →
  0.526) is measured rather than assumed. The conclusion that it cannot
  license individual-level weights follows from the sample size and the
  aggregation mismatch, not from the fit quality alone.
- **It does not prove the 2022/2024 accounting residual's cause.** It
  proves the residual exists, is small relative to any individual player's
  value, and does not affect the row-level identity every published
  per-player value depends on.
- **It does not establish that a role-specific award (Section O's
  specification) would be well-received or complete.** It establishes that
  the specification's inputs, baselines and units are each already
  validated, individually, by Phases 6-10.
