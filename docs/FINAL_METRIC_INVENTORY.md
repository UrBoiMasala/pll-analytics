# Final metric inventory

273 named metrics inventoried from all four existing definition catalogs, contextual counts, and Phase 13 outputs. Technical IDs, flags, validator counts and raw schema fields are not statistical metrics. The machine-readable CSV retains formulas, sources, interpretations and every decision field.

Aliases and redundant units marked SIMPLIFY map to the canonical names in FINAL_METRIC_CATALOG. ARCHIVE does not mean the formula is wrong; it means it is outside the final product. These decisions override old CORE/production labels.
